# 瓷时集

《瓷时集》是一个围绕中国陶瓷发展史展开的互动展览，由三个内容板块共同构成：

- **陶成**：沿汉晋、唐、五代、宋、元、明、清至近现代的时间脉络，呈现各时期代表瓷器、工艺特征与时代审美。
- **琢土**：运用《陶冶图卷》的十二幅制运图景，讲解陶瓷从原料、成形、施釉到烧成的工序体系。
- **观器**：选取八件代表瓷器，通过三维模型、器物特征与馆藏记录进行沉浸式细读。

网站包含桌面、平板与移动端布局，并支持 `prefers-reduced-motion`。

## 本地运行

三维模型、视频和数据资源必须通过本地服务器打开。直接双击 `index.html` 会被浏览器安全策略阻止，无法加载三维模型。

最简便的方式是双击 `start-gesture.cmd`，它会自动启动服务器并打开正确地址。也可以手动运行：

```powershell
node serve.cjs
```

然后访问 `http://127.0.0.1:4327/`。

## 交互

- 鼠标滚轮或触控板：切换作品
- 横向拖拽：浏览海报
- `←` / `→`：切换作品
- `Enter`：打开沉浸式作品浏览
- `Space`：翻转当前海报
- 浏览界面内 `←` / `→`：切换作品
- 浏览界面内 `I`：展开或收起作品信息
- 浏览界面内 `Esc`：收起信息或返回画廊
- 顶部“观器”：打开器物观察界面，查看当前作品的器物资料与观察札记
- 观器界面内 `←` / `→`、滚轮、横向拖拽或相邻图版：循环观察上一件或下一件器物
- 器物细读页鼠标按住上下左右拖动：360° 旋转三维模型查看各角度细节
- “汉晋·新平治陶”“唐代·昌南贡瓷”“五代·素瓷奠基”“宋代·景德影青”“元代·青花初扬”“明代·御窑流光”“清代·陶冶成图”与“近现代·窑火新生”使用无边框的全舞台三维器物模型
- 模型页在空闲时预取当前与相邻器物，并使用上一帧快照交叉淡化，避免首次进入和切换时闪屏
- 顶部“索引”：查看全部 8 部作品

页面包含桌面、平板与移动端布局，并支持 `prefers-reduced-motion`。
